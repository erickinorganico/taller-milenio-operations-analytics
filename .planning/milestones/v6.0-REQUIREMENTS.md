# Milenio V6 — Analytics y automatización operativa

El usuario aprobó resolver las brechas analíticas y de automatización identificadas y añadió un dashboard principal con piezas y servicios más usados. Ejecución autónoma autorizada; decisiones recomendadas se resuelven sin repetir preguntas. V5 se conserva como hito técnico previo, no como cumplimiento de este alcance.

## Requisitos del hito

- [x] **ANA-01**: Gerencia abre un dashboard principal con filtros de fechas y segmento y comparación con un periodo anterior de igual duración.
- [x] **ANA-02**: Puede identificar refacciones consumidas y devueltas desde movimientos reales, con unidades y órdenes, sin confundir compras o reservas con consumo.
- [x] **ANA-03**: Puede identificar servicios y mano de obra autorizados y facturados, sin duplicar versiones de cotización ni inferir ejecución desde una descripción.
- [x] **ANA-04**: Puede comparar facturación, cobros y actividad diaria con fechas de negocio distintas, y consultar saldos y atrasos al corte.
- [x] **ANA-05**: Puede consultar tiempos de entrega y espera donde haya eventos suficientes, con cobertura explícita.
- [x] **ANA-06**: Los análisis se materializan desde la base operativa V5 en cortes persistentes con huella, hora, fuentes y tablas analíticas; cortes previos no cambian al modificar la operación.
- [x] **ANA-07**: Puede explorar y exportar tablas derivadas y seguir sus referencias hasta los registros fuente con control de acceso.
- [x] **AUT-01**: Un trabajador local actualiza analytics y ejecuta revisores por intervalo y cambios de negocio, sin necesitar pulsar un botón.
- [x] **AUT-02**: Gerencia puede pausar/reanudar y configurar frecuencia y modo; el modo predeterminado es reglas y la inferencia opcional queda explícita.
- [x] **AUT-03**: Las ejecuciones conservan disparador, estado, intentos, error, corte y corridas de agentes; existe deduplicación, recuperación y reintentos acotados.
- [x] **AUT-04**: La interfaz muestra latido del trabajador y fallos; cerrar el servidor detiene el trabajador y reiniciar recupera trabajo seguro.
- [x] **AGT-04**: La revisión automática utiliza datos operativos actuales y conserva propuestas con evidencia, sin duplicar tareas ni ejecutar acciones externas.
- [x] **AGT-05**: El circuito muestra análisis, ejecución, propuesta, decisión, responsable y resultado observado; conserva las verificaciones de evidencia obsoleta.
- [x] **DEL-05**: Instalación, migración desde V5, respaldo/restauración y paquete incluyen la nueva capa; pruebas y manual documentan las fronteras reales.

## Fuera de este hito

No se inventan datos históricos previos a la captura, correspondencias semánticas entre servicios, rentabilidad neta, capacidad del taller ni impacto causal. No se activa SaaS multiempresa, mensajes a terceros, compras, cobros externos o diagnóstico mecánico autónomo. El warehouse sintético V1–V4 permanece histórico; los nuevos marts provienen directamente de V5.
