# Acceso, arranque y recepción

**Goal:** Una instalación vacía o demo separada arranca y un usuario autorizado conserva clientes, vehículos, citas y órdenes tras reinicio.

## Execute

1. Crear proyecto Django 5.2, configuración local segura, migraciones, lanzador Windows con Waitress y comandos de instalación vacía/demo sintética. Generar credencial administrativa al instalar, sin contraseña fija.
2. Crear usuarios/roles y permisos en servidor para gerencia, recepción, técnico, refacciones, administración y consulta. Aplicar login, logout y CSRF a escrituras.
3. Modelar cliente, vehículo, cita y orden con propietario, fechas reales y relaciones; exponer operaciones de creación y consulta con validación.

## Verify and evidence

- Migrar base temporal vacía, crear un usuario y probar login/logout, ruta privada anónima, CSRF y operaciones permitidas/prohibidas por rol.
- Crear una orden, reiniciar servidor y confirmar los mismos ID/datos. Lanzar demo en base distinta y comprobar que la base vacía sigue vacía.
- Guardar en SUMMARY comandos, salida, rutas modificadas y resultado de cada requisito. Marcar pending cualquier prueba no ejecutada.
