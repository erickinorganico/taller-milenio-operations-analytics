# Agentes, revisión y tareas

**Goal:** Operación, cobranza y calidad generan propuestas verificables; la decisión humana produce seguimiento interno una sola vez.

## Execute

1. Ejecutar recopilación acotada de evidencia actual por dominio; persistir ejecución, versión/frescura de fuentes, hallazgos, propuesta, errores y método de generación.
2. Implementar modo opcional de CLI Codex nativa autenticada con timeout, salida JSON conforme a esquema y registro visible de error. Reglas exactas siguen deterministas.
3. Crear revisión aceptar/rechazar, comprobación de propuesta vigente, tarea interna idempotente con responsable/plazo, cierre y evaluación posterior. Sin comunicación externa automática.

## Verify and evidence

- Ejecutar agente en fixture y seguir evidencia hasta propuesta; intentar aceptar dos veces y después de cambiar fuente. Confirmar una tarea o rechazo por obsolescencia.
- Probar salida inválida, timeout y CLI ausente. Si la CLI autenticada está disponible, registrar una invocación real con salida validada; si no, dejar AGT-03 pendiente explícitamente.
- Registrar decisiones, tareas y reevaluación en SUMMARY.
