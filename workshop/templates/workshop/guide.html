Guía del taller

Cómo trabajar con una orden

Empieza el turno

Abre Hoy en el taller para ver los trabajos pendientes. En el celular, toca Menú para cambiar de pantalla. Desde Órdenes de trabajo puedes buscar por folio, placas o nombre del cliente.

{% if cap.manage %}

Prepara las cuentas del equipo

En Equipo y acceso, crea una cuenta individual y asigna el rol de cada persona. Para preparar un teléfono consulta la guía infra/CELULAR.md del paquete de instalación.

{% endif %} {% if cap.reception %}

Recibe el vehículo y registra la autorización

Abre Recibir vehículo. Si ya está registrado, selecciónalo por sus placas y propietario. Si es su primera visita, registra el cliente y su vehículo. Escribe qué pide revisar, asigna responsable y fecha prometida cuando los conozcas. Al guardar se abre el folio que usarás para consultar el trabajo.

Desde la orden, crea el presupuesto, agrega mano de obra, refacciones y servicios y márcalo como presentado. Cuando el cliente autorice, registra su nombre y la referencia de la autorización. La versión aprobada queda protegida.

Captura una hoja de servicio

En Documentos y excepciones, sube una foto completa y legible. Cuando termine la lectura, compara los campos y servicios con la hoja, corrige lo que haga falta y confirma la revisión. Abre la vista previa y aplica los cambios para vincular la foto a la orden. El OCR local viene seleccionado de inicio.

{% endif %} {% if cap.work %}

Inspecciona y termina el trabajo

Abre el folio en Mis órdenes. En Inspección, anota los puntos revisados y adjunta las fotos. En trabajo, registra los minutos y cualquier espera de refacciones. En Control de calidad, documenta la comprobación. Si falla, corrige y repite la revisión.

{% if cap.reception %}

Una vez aprobada la revisión, marca la orden lista y registra la entrega cuando el cliente reciba el vehículo.

{% endif %} {% endif %} {% if cap.stock %}

Registra las refacciones

En Refacciones, registra proveedores, piezas y existencias iniciales con un ajuste documentado. Desde la orden puedes reservar y consumir piezas. La compra aumenta las existencias cuando se registra su recepción.

{% endif %} {% if cap.finance_read %}

Consulta el saldo

Caja y cobranza muestra comprobantes y saldos. {% if cap.finance %}Emite el comprobante administrativo desde el presupuesto aprobado y registra cada pago con su referencia. La facturación fiscal y la conciliación bancaria se realizan por separado.{% endif %}

{% endif %} {% if cap.intelligence_read %}

Revisa resultados y pendientes

Métricas explica el cálculo y las fuentes. En Agentes y acciones puedes consultar propuestas y su evidencia.{% if cap.review %} Al aceptar una propuesta vigente, asigna responsable y documenta el resultado.{% endif %}

{% endif %}

Si se corta la conexión del celular

Vuelve a conectar el perfil del taller. Abre tu favorito y busca la orden por folio o placas. Comprueba el último cambio antes de repetir una operación.

{% if cap.manage %}

Respaldo y continuidad

Configura un respaldo privado fuera del disco del servidor y ensaya la restauración con el procedimiento de instalación. Usa la demo para practicar con datos ficticios.

{% endif %}
