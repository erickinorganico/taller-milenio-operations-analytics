# Milenio V6 · Workshop operations, analytics and automation

Local Spanish-language Django application covering intake, inspection, estimates and approval, work orders, parts/purchasing, quality checks, delivery and administrative collections. Includes fleet contracts, maintenance plans and towing milestones. SQLite stores 24 domain tables; 18 live metrics trace back to records. Three governed review agents produce evidence-bound proposals and human-owned action tasks.

V6 adds a management dashboard with date/customer filters, equal-period comparisons, parts consumption and service rankings, daily billing versus collections, delivery/wait coverage and six persisted analytical tables. Every cut retains its source fingerprint and record references. A supervised worker refreshes analytics and runs reviewers after business events or on an interval while the server remains open. The UI exposes pause/resume, bounded retries, heartbeat, errors and links from jobs to cuts and agent runs. Rules are the default; native inference is optional.

Run `Setup-Web.ps1`, then `Iniciar-Demo.cmd` for synthetic data or `Iniciar-Milenio.cmd` for an empty installation. Windows x64/Python 3.12 is the tested target; the delivery ZIP includes offline dependency wheels. Persistent data defaults to LocalAppData, outside the source folder. The server binds to loopback only.

Rules mode is fully local. A real optional native Codex CLI run with GPT-6 Luna completed on synthetic demo data, produced valid structured output and changed no business records (`artifacts/v5-native-verification.json`). Its empty proposals list is valid. The historical V5 suite passed 71/71 tests. The V6 suite ran 115 tests: 113 passed and two fixed-port launch checks skipped because local ports were occupied. A separate extracted-package smoke verified an actual authenticated server on an ephemeral port. Three V6 native reviewers subsequently completed with GPT-6 Luna, producing 14 reviewable proposals on synthetic data. There is no paid API fallback. Financial documents are administrative records, not fiscal invoices. Real workshop adoption, deployment acceptance and business impact require a pilot.
