# Client handover and acceptance

- [ ] Deliverable scope and version recorded.
- [ ] Snapshot cutoff, source owner, and retention location recorded.
- [ ] Data-request checklist reviewed; missing and unknown fields remain visible.
- [ ] Consent and anonymization decisions documented.
- [ ] Reconciliation, freshness, and reference checks reviewed.
- [ ] Action tracker and approval log handed over.
- [ ] Public research sources are openable and marked for human review.
- [ ] Limitations recorded: synthetic/demo versus authorized real snapshot.
- [ ] No external message, dispatch, payment, price change, or repair approval
      was performed by the toolkit.
- [ ] Client acceptance decision: pending / accepted / accepted with follow-up.
- [ ] Client approver, date, and next review owner recorded.
