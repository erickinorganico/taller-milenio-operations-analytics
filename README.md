# Taller Milenio Operations & Growth Analytics

Toolkit local de Analytics y consultoría con **datos sintéticos reproducibles**.

Modela particulares, taller, refacciones, flotillas, grúas y administración;
produce análisis, reportes estáticos y recomendaciones con evidencia para revisión
humana. No opera el taller, no contacta clientes y no mueve dinero.

## Estado

En construcción. Alcance corregido adoptado el 22 de septiembre de 2026.
Los hitos se publican después de verificarlos. El cierre requiere pipeline,
reportes, pruebas, documentación bilingüe y revisión adversarial.

Consulte [alcance](PROJECT.md) y [plan](docs/PLAN.md).
